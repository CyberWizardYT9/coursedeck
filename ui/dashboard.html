Put your due dates in your calendar app

This makes a file with everything that has a date on it. Open that file and your calendar app will offer to import it.

  1. Press Download the file below. It saves as coursedeck.ics.
  2. iPhone / Mac: open the downloaded file — Apple Calendar offers to add the events.
    Google Calendar: calendar.google.com → Settings → Import & export → Import → pick the file.
  3. Do it again whenever you want to refresh. This is a one-time copy, not a live link.
